# Event HUB

Веб-приложение для централизованного управления регистрацией участников на мероприятия. Система предназначена для организаторов событий и потенциальных участников.

## Назначение

Система решает проблему ручного учета заявок через электронную почту или бумажные анкеты. Она обеспечивает формирование актуального списка зарегистрировавшихся, автоматическую фиксацию статусов и контроль посещаемости.

## Основные возможности

Для участника:
- Просмотр каталога мероприятий с фильтрацией по дате и категории.
- Регистрация на событие с указанием контактных данных (ФИО, email, телефон).
- Личный кабинет с историей регистраций и текущими статусами.
- Отмена собственной регистрации.

Для организатора:
- Панель аналитики с ключевыми показателями (количество регистраций, активные события, выручка, процент отказов).
- Реестр регистраций с фильтрацией по статусу и участнику.
- Управление статусами заявок (подтверждение, отмена, отметка о посещении).
- Экспорт списка участников в формате CSV.
- Просмотр истории изменений статусов.

Для администратора:
- Управление пользователями системы (изменение ролей, блокировка аккаунтов).

## Технологический стек

- Backend: Python, Flask
- Frontend: HTML, CSS, Jinja2
- База данных и аутентификация: Supabase (PostgreSQL, Auth)
- Деплой: Render

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-repository>
   cd mini-pet-m
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения. Создайте файл `.env` в корне проекта на основе примера `.env.example`:
   ```text
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_anon_key
   SUPABASE_SERVICE_KEY=your_supabase_service_role_key
   FLASK_SECRET_KEY=your_secret_key
   ```

4. Инициализируйте базу данных (опционально, для тестовых данных):
   ```bash
   python -m db.seed
   python -m db.seed_users
   ```

5. Запустите приложение локально:
   ```bash
   python -m src.app
   ```
   Приложение будет доступно по адресу `http://127.0.0.1:5000`.

## Деплой

Приложение настроено для автоматического деплоя на платформу Render.
Команда запуска: `gunicorn src.app:app`
